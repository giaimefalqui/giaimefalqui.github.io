OptiLTS

Ecurie-Aix Formula Student Team

This project involved developing a comprehensive Optimal Control framework to minimize lap time for a 4-wheel-drive electric Formula Student vehicle. The system combines advanced control theory with vehicle dynamics simulation.

  • Mathematical formulation of the Optimal Control problem:
    $$\text{Minimize} \quad J = \int_0^S L(x(s), u(s), s) \, ds$$
    $$\text{subject to:} \quad \dot{x} = S_{CF} \cdot \alpha(x(s), u(s), s) \quad s \in [0, S]$$
    $$u_L \leq u(s) \leq u_g$$
    $$c_i \leq 0$$
  • Integration of vehicle dynamics model with tire friction constraints.
  • Development of efficient numerical solver using CasADi framework in MATLAB.
  • Used to support vehicle setup and concept decisions.
  • Interactive GUI for setup, simulation, and results analysis.
